\# Smart Attendance System



A Python-based Smart Attendance System that uses face recognition and

OpenCV to automatically identify registered students and record their

attendance.



\## Features



\- Student face registration

\- Face detection

\- Face recognition

\- Automatic attendance marking

\- Multiple face recognition

\- Lecture slot management

\- Attendance record generation

\- Real-time webcam processing

\- GUI-based interface



\## Technologies Used



\- Python

\- OpenCV

\- Face Recognition

\- NumPy

\- Tkinter

\- Pillow



\## How It Works



1\. Register a student's face.

2\. Capture face images using the webcam.

3\. Generate and store face encodings.

4\. Start the attendance system.

5\. Detect faces through the webcam.

6\. Match detected faces with registered students.

7\. Record attendance for the current lecture slot.
